# Do Not Track Me · 自定义指纹与追踪观察

## 安装／升级

在 Chrome 125+ 打开 `chrome://extensions`，开启开发者模式，加载本目录。已有旧版时点击扩展的「重新加载」，再刷新原来的所有网页，旧页面已经安装的拦截代码不会自动消失。工具栏弹窗查看访问证据，点击「指纹后台」打开独立配置页面。

v2 已移除 Canvas、音频分析、离线音频、WebGL 读回和 WebGPU 的强制拒绝。网络拦截与 WebRTC 策略是独立开关，不是假造浏览器指纹；当前默认值以 v2.6.1 下述规则为准，已有手动保存的选择保留。

v2.2 修复了 Canvas 读回像素篡改和等价调用差异，改为稳定的文本绘制偏移；原始种子不再发往网页，停用只发送无档案的控制消息。恢复原生会撤销本扩展安装的 API 属性描述符，不覆盖页面之后自行安装的替换。任意自定义身份与所有 Worker 的一致性仍未解决，不能把本次修复理解为完整指纹模拟。

v2.3 增加 Worker 调试同步。`debugger` 必须在安装或更新时声明，Chrome 不支持运行时申请此可选权限；请确认新增权限提示。v2.4.1 在未保存过同步模式时默认自动连接所有 HTTP(S) 网页；已保存的模式不被覆盖，可在弹窗中直接切换。

v2.5.1 按用户指定的 `cejckpjfigehbeecbbfhangbknpidcnh` 3.0.0 对齐时区算法：页面和受支持 Dedicated Worker 共用 Date 子类及内部偏移日期对象，不由时区模块改写原生 Date.prototype。页面仅由内容脚本安装时区，调试路径只给 Worker 安装，不在页面重复叠加。Intl.DateTimeFormat 按对照扩展强制采用所选时区。保留本插件现有配置、页面注册和总开关恢复接口；不是整个扩展的逐字复制，也不承诺相同的验证码结果。其他防护和自动同步模式未改变。

v2.6.0 增加全局「功能排查开关」。开关独立保存，不清空指纹参数；关闭后刷新页面，不再安装对应功能的改写代码。API 观察与 DNT/GPC 隐私信号也可单独关闭，用于排除观察钩子或请求头造成的影响。

v2.6.1 默认关闭屏幕尺寸替换、WebGL 标识替换、指纹 API 观察、语言替换，其余 11 项规则默认开启（含追踪域名、本地端口、WebRTC）。这是开关默认值，不更改档案内的时区、语言、硬件值或 Canvas/音频选择；已有保存的开关不会自动覆盖。设置页「重置为默认配置」可立即应用此组合。

v2.6.2 将首次使用的默认时区设为 `Asia/Singapore`（新加坡，UTC+8）。已有保存的时区（包括留空跟随系统）保持不变；功能开关的「重置为默认配置」仍不覆盖时区或档案参数。

## 功能排查开关

设置页顶部可以逐项开关：时区、语言、CPU、内存、屏幕、WebGL、Canvas、音频、字体、指纹 API 观察、DNT/GPC、Worker 调试同步，以及追踪域名、本地端口、WebRTC 网络规则。点击立即保存，不需要再点参数区的保存按钮。网络防护区的同名开关也独立立即保存。

- **全部关闭（基线）**：关闭上述全部项目，但不改变全局防护总开关。刷新测试页后，不再启用本扩展的页面 API 改写、请求头改写、调试同步和请求拦截；扩展仍安装着，隔离环境通信和网络观察可保留，不等同于卸载扩展。
- **只开此项**：关闭其他所有项目，包括网络规则，仅保留选中项。也可以自行逐项勾选，比较组合影响。
- **重置为默认配置**：恢复上述四关、其余开启的规则组合。仅重置功能与网络开关，不更改全局总开关、指纹参数、种子、站点绑定或自动调试模式。追踪域名／本地端口拦截及 WebRTC 限制会开启，可能影响本地服务和通话。
- **保留参数**：不清空种子、时区、语言、硬件值、档案、站点绑定或自动调试模式；这些开关同样限制绑定档案。关闭规则不会删除此前填写的值。
- **开启不等于凭空替换**：使用已保存的参数。时区留空、CPU/内存为 0、字体为 native、档案 Canvas/音频未开启时，打开排查开关不会自动生成新值。请先保存要比较的参数。
- **Worker 的依赖**：只开时区可比较页面时区；再勾选 Worker 同步才覆盖受支持 Worker。只开 Worker 而关闭所有身份字段规则，可单独比较调试连接，沿用现有手动/自动模式。
- **每轮刷新**：保存会停止旧调试同步，规则关闭不追回网站缓存的旧值、对象和函数。每次切换之后都刷新测试页，再手动完成一轮验证码；不要靠同一页面反复切换的结果下结论。

「指纹 API 观察」不是无侵入的：观察方法需要包装部分 API，包括已经关闭数值替换的类别，可能本身就是异常来源。要排除某项的观察包装，还应关闭 API 观察；「只开此项」会自动排除其他观察层（除非选中的正是观察）。关闭观察不会关闭其他明确开启的替换。Canvas 字体替换与文本微扰共用绘制入口，因此另一项仍开启时，该入口仍可能被包装。

默认关闭的四项均涉及网页 JS 接口改写或包装。避免这类 JS 包装，需要指纹浏览器等浏览器级支持；普通扩展不能同时保证自定义读数和接口完全原生。观察接口本身也可能产生可检测痕迹；其他替换项并不因此变成原生实现，指纹浏览器也不保证不可检测。


## 自定义与指纹列表

- 后台可手动编辑种子、Canvas 文本绘制微扰、可选音频分析扰动、CPU、内存、屏幕宽高、WebGL 厂商／渲染器、字体策略、语言列表和时区。
- 随机生成得到一套新档案；列表中的档案可命名、编辑、设为默认或绑定到网站。同一档案不会在每次刷新时自动重新随机。随机参数组合不是完整硬件或浏览器模拟：不会同步改变真实 GPU 能力、WebGPU、CSS 媒体查询、UA 或所有 Worker 读数，也不能保证免于验证码。
- 网站绑定按完整主机名匹配：`example.com` 和 `www.example.com` 是两个网站，不支持通配符；输入网址时取主机名，协议、端口和路径不参与绑定。未绑定的主机使用默认设置。iframe 按它自己的源主机选择档案，不继承顶层网站的档案。
- 本地时间使用 IANA 时区，首次使用默认 `Asia/Singapore`（新加坡，UTC+8）。可改为其他 IANA 时区；主动留空用系统时区，已有保存的选择不会因升级改变。不改 IP、操作系统时钟或代理。
- 默认语言为英语 `en-US,en`；旧档案升级时补齐此默认值。后台「语言列表」按优先级填写逗号分隔的 BCP 47 标签，例如 `fr-FR,fr,en`，最多 10 项，自动规范大小写并去重；留空跟随浏览器。随机生成保留编辑区语言；保存到所选记录即可按网站绑定。
- 配置保存后会在受支持的已加载页面异步更新，但网站可能缓存旧值、旧 API 引用或已创建的 Intl 对象。每次保存、生成并应用、更新记录或变更绑定后，都建议刷新受影响网站；时区、全局启停和网站绑定更改后必须刷新。页面级注入与扩展存储读取之间仍存在短暂窗口，最早的同步脚本可能读到原值，刷新也不意味着覆盖所有读取。
- 普通内容脚本不覆盖所有 Worker。开启调试同步后，为普通／模块／blob／嵌套 Dedicated Worker 安装语言、时区、CPU 和内存替换。时区使用与页面相同的 Date 子类算法；仅内容脚本而没有调试连接时，不覆盖 Worker。SharedWorker、Service Worker 不在保证范围内。
- 「默认指纹恢复原生」会保存原生默认读数与字体、关闭档案中的 Canvas／音频微扰，并清空默认语言列表和时区。已有档案、站点绑定、网络设置及独立规则开关不变；已绑定网站仍使用各自档案。显式开启的 API 观察或隐私信号仍可安装钩子；要排除本扩展 API 改写，请使用「全部关闭（基线）」并刷新。

## 一键隐私模式与 Worker 调试同步

### 一键总开关

弹窗顶部的「关闭全部防护／开启已保存的防护」立即保存，无需再点保存。关闭会停止所有调试同步、停用指纹替换与本扩展的网络防护；指纹档案、网站列表、调试模式及各项网络选项仍然保留。重新开启恢复已保存的选择，不随机生成指纹，也不擅自打开原先关闭的网络选项。

网站可能缓存旧值、旧函数或 Intl 实例，关闭后仍建议刷新。重新开启时，已撤销的页面钩子也需要刷新重新安装；自动调试启动可能自行刷新符合条件的标签页。

### 调试同步范围

工具栏弹窗的「Worker 同步 → 同步范围」可以直接切换模式并立即保存。指定网站列表在指纹配置面板的「Worker 同步」中填写，点击「单独保存同步模式」应用：

- **仅手动启动**：在目标网页弹窗点击「启动同步」。
- **仅指定网站自动启动**：每行一个主机名或 HTTP(S) URL，最多 200 个。精确匹配主机；`example.com` 不包含 `www.example.com`。端口、路径、查询和片段不参与匹配，国际域名会规范化，不支持通配符、凭据及其他协议。
- **所有 HTTP(S) 网站自动启动（默认）**：未保存模式时自动采用；已有手动或指定网站设置仍然保留。不接管 `chrome://`、扩展页等内部页面。

自动列表与指纹档案的站点绑定独立：前者决定是否自动连接，后者决定使用哪套参数。保存自动模式会应用到已打开的符合条件标签页及后续访问；连接完成会刷新页面，因此全部网站模式可能同时刷新多个标签页。首次自动连接前已执行的页面代码不受追溯修改，应以连接后的刷新和弹窗状态为准。

「停止同步」会同时暂停该标签页的自动连接；刷新、导航、后台重启及总开关切换不会清除这个暂停。手动点击「启动同步」或关闭标签页才能解除。切换模式或移除网站，只停止不再符合条件的自动会话，不停止另外手动启动的会话；总开关关闭则停止全部会话。

弹窗直接提示：Chrome 可能显示“此扩展正在调试此浏览器”的调试提示条；不是网站报错。DevTools 或其他调试器可能冲突；外部断开不会立即重试，自动模式可在后续导航恢复。保存指纹／时区／档案绑定会停止现有同步；自动模式可在下一次导航或刷新恢复，手动模式需重新启动。失败不会在同一页面上不断重试。

以弹窗真实状态为准：拥有权限或保存了自动模式不等于已经连接；没有 Worker 时数量可以为 0。停止会尝试撤销本扩展拥有的修改，但已缓存的值和函数仍需刷新清除。

这不是完整浏览器内核模拟，不同步 GPU／WebGPU、Canvas Worker 绘制或所有特殊环境，也不承诺无法检测或免验证码。时区行为按对照扩展处理：Date 子类以内部偏移对象提供本地读数，偏移按安装时当前日期固定；不再对历史日期逐个重算 DST、重写 Date.parse 或 Temporal。Intl.DateTimeFormat 会覆盖显式传入的 timeZone。作为 class，替换后的 Date 不能无 new 调用。这些都是所选方案的兼容性取舍，不额外添加伪装或修正层。

时区替换仍是 JavaScript 实现：Date 子类中的 getTimezoneOffset 并不是原生函数，但不再覆盖原生 Date.prototype 上的方法。清空当前实际生效档案（默认或站点绑定档案）的时区并刷新可退出时区替换；关闭总开关保留恢复原生的衔接，旧对象和旧函数引用仍建议通过刷新清除。不要同时启用两个时区扩展，以免叠加覆盖。

**验收状态：按要求未进行新版浏览器或验证码测试。旧版的验证不能作为 v2.6.2 的兼容性证明。**

## 替换，而不是隐藏

以下行为受全局总开关及对应功能规则控制；规则关闭时不执行该项替换。

| 项目 | 行为 |
| --- | --- |
| Canvas | 仅在 `fillText`／`strokeText` 文本绘制时施加基于稳定种子的亚像素偏移，同一档案同一 origin 保持稳定。纯填色、清除和路径绘制像素保持原生；`getImageData`、导出及其他读回不再修改像素，等价读回调用（例如数字与等价数字字符串坐标）遵循原生语义。导出、captureStream 和 transferToImageBitmap 使用实际已绘制图像，包括文本偏移；不在这些操作中额外扰动，也不保证每次更换种子都会得到不同像素。跨源画布限制保持原生。 |
| WebGL | 保留扩展和像素读取能力。原生支持 debug renderer 扩展时，替换其中的厂商和渲染器字符串；不会假装硬件支持它没有的能力。GPU 能力参数仍为真实值。 |
| WebGPU | 完整保留原生能力，仅观察；不是自定义 GPU 配置的覆盖范围。 |
| 音频 | 播放、录制、离线渲染和音频缓冲区保持原生。可选扰动只修改分析器返回数组中的一个值，不影响音频图；默认不启用。某些音频指纹仍能测到真实特征。 |
| CPU／内存 | 替换 JavaScript getter 的数值；填 0 使用原生值，不改变真实计算资源。 |
| 屏幕 | 替换 screen.width/height/availWidth/availHeight；宽高均填 0 使用原生值。不修改窗口、设备缩放、CSS 媒体查询或触摸能力。 |
| 字体 | 可把普通 DOM 与 Canvas 文本统一为 sans-serif、serif 或 monospace；原生模式不改变。会影响排版和字体图标。不删字体，不伪造字体不存在；queryLocalFonts、FontFaceSet、下载字体、Shadow DOM、SVG 和 CSS 侧信道仍可能泄露字体信息，不能声称完全替换系统字体清单。 |
| 时间 | 页面与受支持 Dedicated Worker 使用同一套 Date 子类和内部偏移对象，原生 Date.prototype 不被时区模块改写。Intl.DateTimeFormat 强制采用所选时区，包括覆盖显式 timeZone。偏移按安装时的当前日期固定；Date.parse、UTC 静态方法和 Temporal 不增加替换。页面由内容脚本安装，Worker 由调试连接在脚本执行前安装，调试路径不重复修改页面时区。 |
| 语言 | 同步页面 navigator.language/languages、常用 Intl 构造器和 toLocale 方法的默认区域；显式传入的区域不改。HTTP(S) Accept-Language 自动按 1.0、0.9…生成权重：默认 `en-US,en;q=0.9`。请求头按实际目标主机的绑定／默认语言处理，跨域资源不继承来源网页档案。原生模式下，必要时按 Chrome 语言偏好恢复请求头。受支持 Worker 需要手动或按所选自动模式连接调试同步；已加载页面和已创建 Intl 对象需刷新更新。 |
| UA、Cookie、布局、设备授权 | 监测常见 API，不伪造 UA 或设备列表，不删除 Cookie／登录态；Client Rects 不独立伪造，但字体替换可能改变布局。 |

## 本地端口／Clash

网页可能连接回环或局域网地址，利用成功、失败和耗时推测监听端口；端口开放不等于证明安装了 Clash。端口状态不是浏览器可填写的 getter，因此**没有“替换开放端口”的功能**。

可选「阻止本地端口探测」会使用 Chrome DNR 阻断 URL 直接指向回环、常见私网、链路本地 IPv4、localhost／.local 及相应 IPv6 地址的 HTTP(S)／WebSocket **子请求**，覆盖所有端口，不只某几个 Clash 默认端口。

- 不访问、不扫描、不配置 Clash，不改代理服务器或监听端口。
- 用户直接打开本地主页的顶层导航不拦，但该页的本地子资源也会被拦；需要管理 Clash、NAS、路由器或开发服务器时请关闭此选项。
- 不是 DNS 防火墙：公网域名解析／重绑定到私网、WebRTC/STUN/UDP 不在这些 URL 规则的保证范围内。WebRTC 限制另有独立开关，可能影响通话。
- 其他网站也可能通过延迟或代理网络特征推断代理使用情况，不能承诺“检测不到 Clash”。

## 面板与数据

「指纹读取」显示 API 类别及首次脚本来源，正常业务也会调用这些接口，因此不等于追踪证据。「已拦截」只有 Chrome 确认规则命中才显示；以已解压方式安装才有此调试事件。「其他跨主机请求」不等于追踪器，CDN、图片和普通资源会列在这里。

档案、网站绑定和设置只存在本地扩展存储。没有上传接口。页面配置桥保留 `dntm-profile` 事件，但只传递需要应用的配置：渲染种子按 frame origin 使用 HMAC 派生，不再传递可跨源复用的原始档案种子或档案记录标识。暂停防护时不向页面发送档案数据，仅发送停用控制信号以恢复原生。派生值仍可能被当前源观察，事件桥和 JavaScript API 包装不是安全隔离边界，网站可以识别或干扰它们。

当前标签页的观测记录只存在会话存储，导航重置；不保存请求正文、完整查询参数、Cookie 或表单内容。Worker、特殊框架、未覆盖 API 和服务端数据仍可能绕过这些替换。恢复原生不撤销网站已经缓存的旧值、旧函数引用或已生成的像素，因此仍建议重新加载页面。

这不是匿名浏览器，也不保证 ToDetect 的“指纹一致性”满分或免于验证码。修改显卡名称而保留真实 GPU 能力可能造成不一致；这些差异本身也不能证明某次验证码的原因。页面发生兼容问题时，先把对应替换项恢复原生，并关闭独立网络限制后刷新。

维护：`node tools/generate-zones.mjs` 生成打包时区映射，`zones/` 已附带。扩展不依赖运行时下载。

## 本地 hCaptcha 对比页面

运行 `node tools/hcaptcha-server.mjs`，在浏览器打开 `http://hcaptcha.test:8787/`。服务器只监听 `127.0.0.1`，不提供项目目录的任意文件下载。Windows hosts 需包含 `127.0.0.1 hcaptcha.test`；hCaptcha 官方不支持直接使用 localhost／127.0.0.1 作为验证码主机名。sitekey 若有域名限制，需要在 hCaptcha 后台允许 `hcaptcha.test`。

凭据保存在项目外的 `%LOCALAPPDATA%/donot-track-me/hcaptcha.local.json`，字段为 `sitekey`、`secret`；也可通过 `HCAPTCHA_CONFIG` 指定文件。secret 只由后端向官方 `https://api.hcaptcha.com/siteverify` 发送，不进入网页、日志或扩展包。该独立测试页会加载 hCaptcha 官方资源，不属于扩展的后台上传行为。

手动完成挑战后点击「提交后端验证」，页面显示官方实际返回的 success、error-codes、hostname 等字段。客户端回调不代表后端通过，不伪造成功；token 只保留在内存中且不显示，每轮提交后重新获取。后端采用 URL 编码 POST 并附带预期 sitekey，本地访问不把回环地址或示例地址当作 remoteip。

先关闭插件并刷新完成一轮，再开启插件、刷新并重新完成一轮；保持相同网络和 sitekey。加载错误、接口网络错误和验证码验证失败分别显示。不同网站的 sitekey 设置及额外风控不同，本页结果不能证明其他网站一定放行。停止服务可在运行它的终端按 Ctrl+C。
